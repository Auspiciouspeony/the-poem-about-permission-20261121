"The Weight" — a short poem about permission: the power to ask and to be given. Asking to hold a newborn, and being given her: she weighs almost nothing and everything, and when she is given back, the arms keep the shape of having been trusted.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), 225 characters, deterministic, standard library only, no network.
